# **App Name**: WhatsApp Sales Bot

## Core Features:

- WhatsApp UI Replication: Mimic the WhatsApp chat interface, including the header, chat bubbles, and input field.
- Automated Message Display: Display a series of automated messages with specified delays between them.
- Interactive Buttons: Render buttons that, when clicked, trigger the next message or action.
- Image Display: Present images within the chat flow as if they were sent in a real conversation, utilizing provided URLs.
- Redirection: Redirect users to a specified external link (https://go.pepperpay.com.br/0qvu6) upon clicking a particular button.
- CSS Styling: Apply custom CSS to mimic the design and button style found in the provided code snippet.

## Style Guidelines:

- Primary color: Dark shade of green (#128C7E), reminiscent of WhatsApp's theme, creates a sense of familiarity and trust.
- Background color: Very light grayish-green (#D9E8E5) for chat bubbles and overall background.
- Accent color: A brighter shade of green (#25D366) for interactive elements like buttons.
- Font: 'Inter' sans-serif, for both body and headlines, providing a clean and modern feel suitable for a chat interface.
- Use simple, recognizable icons from 'material-design-iconic-font' to mirror the WhatsApp interface.
- Arrange the chat interface to match WhatsApp's layout, including a header with user info and a bottom input area.
- Incorporate subtle fade-in animations for new messages to enhance user engagement.
